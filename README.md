# Daily-Dose-Of-Dogs
Utilized: HTML, CSS, JavaScript, GitHub Pages

This app is for anyone who could use a smile!

Inspired by our love for dogs, this fun site shows the user random dog pictures! Filter through dog breeds to see images of your favorite furry friends. Users can also save pictures to their favorites.
